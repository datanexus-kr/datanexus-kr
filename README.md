### 사용량 노트 <sub>2026-09-08 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 8.0B 토큰을 태웠다. API 정가로 환산한 비용은 $11,505로 실제 결제액과는 다르다. 전체 토큰의 94.5%를 캐시에서 읽었다.

툴별로는 Codex $7,704, Claude Code $3,800 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,721으로 절반 가까이 가져간다. Claude 쪽은 claude-opus-5가 $1,326까지 올라왔다.

7월이 $3,817로 월 최고였고 8월은 $1,967로 꺾였다. 하루 최고 기록은 9월초의 $1,049이다. 최근 30일만 떼어 보면 Claude Code $2,181, Codex $1,594로 순서가 뒤집혔다.

#### 비용 인사이트

1. 작업 종류를 함께 기록해야 한다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 업무로 모델을 비교해 가벼운 일에 작은 모델을 붙인다. 내 기록에는 작업 종류가 없어 같은 비교를 못 한다.

2. 캐시 읽기가 94.5%라도 원인은 따로 봐야 한다. 캐시 읽기는 전에 보낸 내용을 다시 쓴 토큰이다. [비용 통제 글](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 매번 다시 실리는 기본 입력과 쌓인 대화를 나눠 재보라고 짚는다.
