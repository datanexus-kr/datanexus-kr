### 사용량 노트 <sub>2026-09-23 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 12.4B 토큰을 태웠다. API 정가로 환산한 비용은 $17,839로 실제 결제액과는 다르다. 전체 토큰의 94.8%를 캐시에서 읽었다.

툴별로는 Codex $13,118, Claude Code $4,719 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-6-astra 하나가 $5,827으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,831까지 올라왔다.

9월이 $8,105로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월 중순의 $1,339이다. 최근 30일만 떼어 보면 Codex $6,089, Claude Code $2,124로 순서가 그대로다.

#### 비용 인사이트

1. 캐시 읽기 비중 94.8%는 전에 보낸 내용을 다시 쓰는 토큰이 많다는 뜻이다. [엔터프라이즈 AI 에이전트 비용 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)는 시스템 프롬프트와 대화 기록이 매 호출마다 다시 실린다고 짚는다.

2. gpt-6-astra 한 모델이 비용의 상당 부분을 차지한다. 작업 종류별로 모델을 나눠 썼는지 점검해볼 만하다. [Codex 멀티 모델 설정 가이드](https://datanexus-kr.github.io/curations/2026-08/2026-08-08-codex-multi-model-agent-cost-optimization/)를 참고할 만하다.
