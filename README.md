### 사용량 노트 <sub>2026-09-07 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 7.8B 토큰을 태웠다. API 정가로 환산한 비용은 $11,240로 실제 결제액과는 다르다. 전체 토큰의 94.5%를 캐시에서 읽었다.

툴별로는 Codex $7,475, Claude Code $3,764 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,697으로 절반 가까이 가져간다. Claude 쪽은 claude-opus-5가 $1,290까지 올라왔다.

7월이 $3,817로 월 최고였고 8월은 $1,967로 꺾였다. 하루 최고 기록은 9월초의 $959이다. 최근 30일만 떼어 보면 Claude Code $2,145, Codex $1,380로 순서가 뒤집혔다.

#### 비용 인사이트

1. 최근 30일 도구 순서가 뒤집힌 이유는 따로 봐야 한다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 비용을 세션 수와 대화를 주고받은 횟수로 쪼개 본다. 이 집계에는 그런 항목이 없다.

2. 같은 내용을 얼마나 반복해서 보내는지 볼 필요가 있다. 전에 보낸 내용을 다시 쓰는 캐시 읽기 비중이 높아도 [비용 통제 글](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 안내문과 도구 설명이 요청마다 다시 실린다고 짚는다.

3. 한 모델에 쏠린 구성은 나눠 볼 여지가 있다. [Codex 설정 글](https://datanexus-kr.github.io/curations/2026-08/2026-08-08-codex-multi-model-agent-cost-optimization/)은 설계와 검토만 상위 모델에 두고 조사와 구현은 하위 모델에 맡기는 방식을 소개한다.
