### 사용량 노트 <sub>2026-09-20 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 10.4B 토큰을 태웠다. API 정가로 환산한 비용은 $15,422로 실제 결제액과는 다르다. 전체 토큰의 94.6%를 캐시에서 읽었다.

툴별로는 Codex $11,015, Claude Code $4,405 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,916으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,573까지 올라왔다.

9월이 $5,688로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월초의 $1,079이다. 최근 30일만 떼어 보면 Codex $4,195, Claude Code $1,863로 순서가 그대로다.

#### 비용 인사이트

1. 작업 종류별로 모델을 나눠 쓸 여지가 있다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 작업으로 모델을 비교해 고른다. gpt-5.5에 $4,916이 몰린 만큼 작업 종류도 함께 기록해볼 만하다.

2. 캐시 94.6%가 곧 절약은 아니다. [비용 통제 글](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 매번 다시 실리는 기본 입력과 쌓인 대화를 비용 요인으로 꼽는다. 다만 이 집계에는 호출 수가 없어 원인까지는 짚기 어렵다.

3. 연결해둔 도구가 입력을 늘렸는지 볼 필요가 있다. [Claude Code 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 도구 정의가 매 요청에 함께 실린다고 짚는다. 안 쓰는 도구가 켜져 있는지 점검해볼 만하다.
