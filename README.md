### 사용량 노트 <sub>2026-09-24 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 12.7B 토큰을 태웠다. API 정가로 환산한 비용은 $18,002로 실제 결제액과는 다르다. 전체 토큰의 94.8%를 캐시에서 읽었다.

툴별로는 Codex $13,155, Claude Code $4,846 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-6-astra 하나가 $5,863으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,831까지 올라왔다.

9월이 $8,268로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월 중순의 $1,339이다. 최근 30일만 떼어 보면 Codex $6,084, Claude Code $2,250로 순서가 그대로다.

#### 비용 인사이트

1. 같은 내용을 얼마나 반복해서 보내는지 볼 필요가 있다. 전체 토큰의 94.8%가 캐시 읽기, 즉 전에 보낸 내용을 다시 쓴 토큰이다. [엔터프라이즈 비용 글](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 큰 조회 결과를 남겨두면 호출마다 다시 전송된다고 짚는다.

2. 모델은 작업 종류에 맞춰 나눠 쓸 만하다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에서는 실제 작업으로 모델별 결과와 비용을 비교해 고른다. 기록에 작업 종류를 남기면 gpt-6-astra에 몰린 비용도 같은 기준으로 비교해 볼 수 있다.
