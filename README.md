### 사용량 노트 <sub>2026-09-28 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 142억 토큰을 썼다. API 정가로 환산한 비용은 $18,783 (₩25,451,720)으로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.0%를 캐시에서 읽었다.

도구별로는 Codex $13,506 (₩18,301,040), Claude Code $5,276 (₩7,148,807) 순으로 Codex가 Claude Code의 2.6배다. Gemini는 약 $1 (₩1,873)이다. 모델별로는 gpt-6-astra가 $6,201 (₩8,403,303)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,481,711)이다.

월별로는 8월은 $2,163 (₩2,930,871)였다. 9월(28일까지)은 $9,049 (₩12,261,725)로 가장 많다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,392 (₩8,661,552), Claude Code $2,680 (₩3,632,139)으로 도구별 순위는 동일하다.

#### 참고

1. 큰 모델이 어떤 작업까지 맡았는지 볼 필요가 있다. [Codex 멀티 모델 설정](https://datanexus-kr.github.io/curations/2026-08/2026-08-08-codex-multi-model-agent-cost-optimization/)에 따르면 설계와 검토는 메인 모델 몫이다. 조사와 구현은 서브에이전트(일을 나눠 받는 보조 에이전트)에게 맡길 수 있다.

2. 9월 비용이 왜 늘었는지는 쪼개 봐야 보인다. [우버의 AI 코딩 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 비용은 세션 수, 대화를 주고받은 횟수, 토큰 수 등의 곱으로 나뉜다. 다음 기록에 세션 수를 함께 남겨볼 만하다.
