### 사용량 노트 <sub>2026-09-27 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 137억 토큰을 썼다. API 정가로 환산한 비용은 $18,558 (₩25,146,456)으로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 94.9%를 캐시에서 읽었다.

도구별로는 Codex $13,397 (₩18,153,340), Claude Code $5,159 (₩6,991,243) 순으로 Codex가 Claude Code의 2.6배다. Gemini는 약 $1 (₩1,873)이다. 모델별로는 gpt-6-astra가 $6,101 (₩8,266,636)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,481,711)이다.

월별로는 8월은 $2,163 (₩2,930,871)였다. 9월(27일까지)은 $8,824 (₩11,956,461)로 가장 많다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,283 (₩8,513,852), Claude Code $2,564 (₩3,474,575)로 도구별 순위는 동일하다.

#### 참고

1. Codex는 메인과 하위 작업 모델을 나눠 쓸 수 있다. [Codex 멀티 모델 설정](https://datanexus-kr.github.io/curations/2026-08/2026-08-08-codex-multi-model-agent-cost-optimization/)에 정리되어 있다. 모델별 환산 비용을 남겨두면 이 분리가 적용되는지 비교할 수 있다.

2. 캐시 비중이 높아도 호출 수는 줄지 않을 수 있다. [엔터프라이즈 에이전트 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에는 비용을 반복 입력, 누적된 정보량, 호출 수로 나눠 봐야 한다고 정리되어 있다. 다음 기록에는 세션당 대화 횟수도 남겨보면 좋다.
