### 사용량 노트 <sub>2026-09-30 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 146억 토큰을 썼다. API 정가로 환산한 비용은 $18,994 (₩25,706,201)로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.1%를 캐시에서 읽었다.

도구별로는 Codex $13,592 (₩18,394,394), Claude Code $5,401 (₩7,309,937) 순으로 Codex가 Claude Code의 2.5배다. Gemini는 약 $1 (₩1,870)이다. 모델별로는 gpt-6-astra가 $6,227 (₩8,427,583)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,478,616)이다.

월별로는 8월은 $2,163 (₩2,927,216)였다. 9월은 $9,260 (₩12,532,656)으로 가장 많다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,454 (₩8,735,002), Claude Code $2,806 (₩3,797,655)으로 도구별 순위는 동일하다.

#### 참고

1. 9월에 늘어난 환산 비용은 나눠서 볼 필요가 있다. [우버의 AI 코딩 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 우버는 비용을 세션 수, 대화를 주고받은 횟수, 토큰 수로 나눠 측정한다. 다음 기록에는 세션 수도 함께 남겨두면 좋다.

2. Codex에서는 모델마다 맡은 역할을 확인해볼 만하다. [Codex 멀티 모델 에이전트 설정](https://datanexus-kr.github.io/curations/2026-08/2026-08-08-codex-multi-model-agent-cost-optimization/)에 따르면 메인 모델은 설계와 검토만 맡고 나머지는 보조 에이전트가 나눠 처리한다. gpt-6-astra를 어떤 작업에 썼는지 기록해두면 좋다.
