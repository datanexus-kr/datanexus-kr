### 사용량 노트 <sub>2026-10-01 기준</sub>

4월 중순부터 여섯 달 동안 AI 코딩 도구로 148억 토큰을 썼다. API 정가로 환산한 비용은 $19,117 (₩25,911,443)으로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.1%를 캐시에서 읽었다.

도구별로는 Codex $13,649 (₩18,500,387), Claude Code $5,466 (₩7,409,182) 순으로 Codex가 Claude Code의 2.5배다. Gemini는 약 $1 (₩1,873)이다. 모델별로는 gpt-6-astra가 $6,283 (₩8,515,317)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,482,352)이다.

월별로는 9월은 $9,366 (₩12,695,155)였다. 10월(1일까지)은 $17 (₩22,885)이다. 월 최고 기록은 9월의 $9,366 (₩12,695,155)이다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,469 (₩8,768,474), Claude Code $2,871 (₩3,891,605)으로 도구별 순위는 동일하다.

#### 참고

1. 9월에 몰린 환산 비용은 나눠서 볼 필요가 있다. [우버의 AI 코딩 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 우버는 비용을 세션 수, 대화를 주고받은 횟수, 토큰 수 등으로 쪼개 측정한다. 다음 기록에는 세션 수도 남겨볼 만하다.

2. 쌓인 작업 기록은 요청마다 다시 보내진다. [에이전트 LLM 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에 따르면 큰 조회 결과를 남겨두면 이후 호출마다 다시 전송된다. 앞서 보낸 내용을 재사용한 캐시 읽기가 많은 것도 이 때문인지 따져볼 일이다.
