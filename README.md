### 사용량 노트 <sub>2026-09-22 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 12.3B 토큰을 태웠다. API 정가로 환산한 비용은 $17,634로 실제 결제액과는 다르다. 전체 토큰의 94.8%를 캐시에서 읽었다.

툴별로는 Codex $12,955, Claude Code $4,678 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-6-astra 하나가 $5,666으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,790까지 올라왔다.

9월이 $7,900로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월 중순의 $1,339이다. 최근 30일만 떼어 보면 Codex $6,011, Claude Code $2,097로 순서가 그대로다.

1. 캐시 읽기 비중이 94.8%다. [Claude Code 토큰 사용량 측정과 비용 절약 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 짧은 시간 안에 재요청하면 캐시 읽기 비용이 낮아진다고 설명한다. 반복해서 보내는 내용이 얼마나 되는지 볼 필요가 있다.
