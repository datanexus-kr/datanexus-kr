### 사용량 노트 <sub>2026-09-29 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 145억 토큰을 썼다. API 정가로 환산한 비용은 $18,952 (₩25,736,085)로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.0%를 캐시에서 읽었다.

도구별로는 Codex $13,581 (₩18,442,213), Claude Code $5,370 (₩7,291,996) 순으로 Codex가 Claude Code의 2.5배다. Gemini는 약 $1 (₩1,877)이다. 모델별로는 gpt-6-astra가 $6,221 (₩8,448,171)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,486,986)이다.

월별로는 8월은 $2,163 (₩2,937,100)였다. 9월(29일까지)은 $9,218 (₩12,518,057)으로 가장 많다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,452 (₩8,760,720), Claude Code $2,775 (₩3,767,853)로 도구별 순위는 동일하다.

#### 참고

1. 9월 급증은 대화 횟수와 세션 수로 나눠 볼 만하다. [우버의 소프트웨어 팩토리 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 비용을 세션, 대화 횟수, 토큰 단위로 나눠 잰다. 집계에는 호출 수가 없어 원인은 알 수 없다.

2. Codex 쪽은 반복 입력의 몫을 확인할 필요가 있다. [AI 에이전트 LLM 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에 따르면 비용은 매 호출에 반복되는 기본 입력, 쌓이는 컨텍스트(함께 보내는 정보), 호출 수로 나뉜다. 다음엔 세션당 요청 수도 남겨볼 만하다.
