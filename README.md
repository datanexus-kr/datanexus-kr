### 사용량 노트 <sub>2026-09-17 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 9.4B 토큰을 태웠다. API 정가로 환산한 비용은 $14,054로 실제 결제액과는 다르다. 전체 토큰의 94.6%를 캐시에서 읽었다.

툴별로는 Codex $9,999, Claude Code $4,054 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,916으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,379까지 올라왔다.

9월이 $4,321로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월초의 $1,064이다. 최근 30일만 떼어 보면 Codex $3,374, Claude Code $1,545로 순서가 그대로다.

#### 비용 인사이트

1. 작업 종류별로 모델을 나눠 쓸 만하다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 작업으로 성능과 비용을 비교해 모델을 고른다. 내 기록에도 작업 종류를 남기면 같은 기준으로 견줄 수 있다.

2. 캐시 94.6%도 같은 내용을 반복해 보낸 결과일 수 있다. 캐시 읽기는 전에 보낸 내용을 다시 사용한 토큰이다. [엔터프라이즈 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)는 조회 결과가 쌓여 매번 다시 실린다고 짚는다.

3. 연결한 도구도 입력을 늘린다. [Claude Code 절약 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 도구 설명이 매 요청에 함께 간다고 설명한다. 안 쓰는 도구가 켜져 있는지 확인해 볼 만하다.
