### 사용량 노트 <sub>2026-10-05 기준</sub>

4월 중순부터 여섯 달 동안 AI 코딩 도구로 153억 토큰을 썼다. API 정가로 환산한 비용은 $19,525 (₩26,325,104)로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.1%를 캐시에서 읽었다.

도구별로는 Codex $13,858 (₩18,683,800), Claude Code $5,666 (₩7,639,440) 순으로 Codex가 Claude Code의 2.4배다. Gemini는 약 $1 (₩1,863)이다. 모델별로는 gpt-6-astra가 $6,460 (₩8,710,164)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,469,312)이다.

월별로는 9월은 $9,366 (₩12,628,467)였다. 10월(5일까지)은 $425 (₩572,541)이다. 월 최고 기록은 9월의 $9,366 (₩12,628,467)이다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,392 (₩8,617,998), Claude Code $2,993 (₩4,035,343)으로 도구별 순위는 동일하다.

#### 참고

1. 도구 간 차이는 비용을 항목별로 나눠 봐야 보인다. [우버의 AI 코딩 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 우버는 비용을 세션 수, 대화를 주고받은 횟수, 요청당 토큰 등으로 나눠 추적한다. 도구별로 이 항목을 남기면 비교 근거가 생긴다.

2. 같은 내용을 얼마나 반복해서 보내는지 볼 필요가 있다. [에이전트 LLM 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에 따르면 큰 조회 결과를 대화에 남겨두면 이후 호출마다 다시 전송된다. 캐시 읽기(이전 요청 내용을 재사용한 토큰)가 많다면 그 신호일 수 있다.
