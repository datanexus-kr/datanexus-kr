### 사용량 노트 <sub>2026-09-21 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 11.6B 토큰을 태웠다. API 정가로 환산한 비용은 $16,713로 실제 결제액과는 다르다. 전체 토큰의 94.7%를 캐시에서 읽었다.

툴별로는 Codex $12,035, Claude Code $4,677 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,916으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,790까지 올라왔다.

9월이 $6,979로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월 중순의 $1,339이다. 최근 30일만 떼어 보면 Codex $5,214, Claude Code $2,134로 순서가 그대로다.

#### 비용 인사이트

1. 캐시 읽기 비중이 높다고 비용이 절감된 건 아니다. 캐시 읽기는 전에 보낸 내용을 다시 사용한 토큰이다. [Claude Code 토큰 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 프롬프트 캐싱이 5분 이내 재요청에서만 효과가 크다고 짚는다.

2. 모델별 비용 차이 원인은 이 집계로 알 수 없다. 어떤 작업에 어떤 모델을 썼는지 기록해두면 비교 기준이 생긴다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 작업으로 모델별 비용과 성능을 따로 측정한다고 설명한다.
