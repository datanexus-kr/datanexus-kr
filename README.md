### 사용량 노트 <sub>2026-10-04 기준</sub>

4월 중순부터 여섯 달 동안 AI 코딩 도구로 153억 토큰을 썼다. API 정가로 환산한 비용은 $19,488 (₩26,275,637)으로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.1%를 캐시에서 읽었다.

도구별로는 Codex $13,830 (₩18,646,598), Claude Code $5,657 (₩7,627,176) 순으로 Codex가 Claude Code의 2.4배다. Gemini는 약 $1 (₩1,863)이다. 모델별로는 gpt-6-astra가 $6,441 (₩8,683,919)으로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,469,312)이다.

월별로는 9월은 $9,366 (₩12,628,467)였다. 10월(4일까지)은 $388 (₩523,074)이다. 월 최고 기록은 9월의 $9,366 (₩12,628,467)이다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,627 (₩8,935,557), Claude Code $2,988 (₩4,028,077)으로 도구별 순위는 동일하다.

#### 참고

1. 비용을 작업 단위로 나눠 기록할 필요가 있다. [우버의 AI 코딩 비용 분해](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 비용을 작업 세션부터 대화를 주고받은 횟수와 요청, 토큰까지 나눠 본다. 다음 기록에는 대화 횟수도 남겨볼 만하다.

2. 쌓인 대화가 요청마다 다시 실리는지 볼 필요가 있다. [에이전트 LLM 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에 따르면 이전 대화와 조회 결과는 다음 요청에 함께 보내진다. 긴 세션을 언제 정리하는지도 확인할 만하다.
