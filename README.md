### 사용량 노트 <sub>2026-09-10 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 8.0B 토큰을 태웠다. API 정가로 환산한 비용은 $11,554로 실제 결제액과는 다르다. 전체 토큰의 94.5%를 캐시에서 읽었다.

툴별로는 Codex $7,751, Claude Code $3,802 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,722으로 절반 가까이 가져간다. Claude 쪽은 claude-opus-5가 $1,328까지 올라왔다.

7월이 $3,817로 월 최고였고 8월은 $1,967로 꺾였다. 하루 최고 기록은 9월초의 $1,049이다. 최근 30일만 떼어 보면 Claude Code $2,009, Codex $1,559로 순서가 뒤집혔다.

#### 비용 인사이트

1. 작업 종류를 기록에 남겨둘 필요가 있다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 작업으로 모델을 비교해 가벼운 작업에는 가벼운 모델을 붙인다. 최근 30일 도구 순서가 뒤집힌 이유도 작업 성격에서 찾아볼 만하다.

2. 캐시 94.5%가 곧 절약을 뜻하진 않는다. [비용 통제 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)는 반복 입력과 쌓인 대화 기록이 호출마다 다시 실린다고 짚는다. 이 집계에는 호출 수가 없어 원인까지는 알 수 없다.

3. 연결한 도구가 기본 입력을 늘릴 수 있다. [토큰 절약 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 도구 설명이 매 요청에 함께 실린다고 설명한다. 안 쓰는 도구가 켜져 있는지 점검해볼 만하다.
