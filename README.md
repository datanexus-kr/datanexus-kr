### 사용량 노트 <sub>2026-10-03 기준</sub>

4월 중순부터 여섯 달 동안 AI 코딩 도구로 151억 토큰을 썼다. API 정가로 환산한 비용은 $19,430 (₩26,197,341)으로, 정액 구독(Claude Max 등)으로 쓰고 있어 실제 결제액은 이보다 적다. 전체 토큰의 95.1%를 캐시에서 읽었다.

도구별로는 Codex $13,809 (₩18,618,411), Claude Code $5,620 (₩7,577,066) 순으로 Codex가 Claude Code의 2.5배다. Gemini는 약 $1 (₩1,863)이다. 모델별로는 gpt-6-astra가 $6,424 (₩8,661,079)로 가장 많다. Claude 쪽은 claude-opus-5가 $1,831 (₩2,469,312)이다.

월별로는 9월은 $9,366 (₩12,628,467)였다. 10월(3일까지)은 $330 (₩444,778)이다. 월 최고 기록은 9월의 $9,366 (₩12,628,467)이다. 하루 최고 기록은 9월 20일의 $1,339 (₩1,858,259)이다. 최근 30일 기준으로도 Codex $6,622 (₩8,928,674), Claude Code $2,953 (₩3,980,998)으로 도구별 순위는 동일하다.

#### 참고

1. 9월에 몰린 사용량은 나눠 볼 필요가 있다. [우버의 AI 코딩 비용 관리](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)에 따르면 총비용을 세션 수, 대화를 주고받은 횟수, 요청당 토큰으로 나눠서 본다. 다음 기록에 세션 수를 함께 남기면 늘어난 지점을 찾기 쉽다.

2. 쌓인 대화가 반복해서 전송되는지 볼 만하다. 캐시 읽기는 앞서 보낸 내용을 재사용한 토큰이다. [에이전트 LLM 비용 통제](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)에 따르면 큰 조회 결과를 남겨두면 이후 호출마다 다시 전송된다.
