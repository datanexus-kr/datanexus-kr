### 사용량 노트 <sub>2026-09-25 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 13.4B 토큰을 태웠다. API 정가로 환산한 비용은 $18,284로 실제 결제액과는 다르다. 전체 토큰의 94.9%를 캐시에서 읽었다.

툴별로는 Codex $13,187, Claude Code $5,095 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-6-astra 하나가 $5,894으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,831까지 올라왔다.

9월이 $8,550로 월 최고였고 8월은 $2,163로 꺾였다. 하루 최고 기록은 9월 중순의 $1,339이다. 최근 30일만 떼어 보면 Codex $6,116, Claude Code $2,500로 순서가 그대로다.

#### 비용 인사이트

1. 같은 내용을 얼마나 다시 보내는지 볼 필요가 있다. 전체 토큰의 94.9%가 캐시 읽기, 즉 전에 보낸 내용을 다시 사용한 토큰이다. [관련 큐레이션](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 큰 조회 결과를 남겨두면 매번 전송된다고 짚는다.

2. 모델별 환산 비용은 작업 종류와 함께 봐야 한다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 가벼운 작업에 경제적인 모델을 기본으로 둔다. gpt-6-astra를 어떤 작업에 썼는지 기록하면 같은 기준으로 비교할 수 있다.
