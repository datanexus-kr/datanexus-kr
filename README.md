### 사용량 노트 <sub>2026-09-15 기준</sub>

4월 중순부터 다섯 달 동안 AI 코딩 도구로 8.8B 토큰을 태웠다. API 정가로 환산한 비용은 $12,639로 실제 결제액과는 다르다. 전체 토큰의 94.6%를 캐시에서 읽었다.

툴별로는 Codex $9,108, Claude Code $3,530 순이고 Gemini는 써본 수준이다. 모델로 좁히면 gpt-5.5 하나가 $4,798으로 가장 많이 가져간다. Claude 쪽은 claude-opus-5가 $1,360까지 올라왔다.

7월이 $3,817로 월 최고였고 8월은 $1,967로 꺾였다. 하루 최고 기록은 9월초의 $1,049이다. 최근 30일만 떼어 보면 Codex $2,685, Claude Code $1,086로 순서가 그대로다.

#### 비용 인사이트

1. 가벼운 작업은 가벼운 모델에 맡길 수 있다. [우버 사례](https://datanexus-kr.github.io/curations/2026-09/2026-09-02-efficient-software-factory-uber-scale/)는 실제 작업으로 모델을 비교해 일의 종류에 따라 나눠 쓴다.

2. 캐시 비중 94.6%가 곧 절감은 아니다. [비용 통제 글](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-enterprise-ai-agent-llm-cost-control/)은 반복 입력과 쌓인 대화, 호출 횟수를 따로 재라고 짚는다. 이 집계엔 호출 수가 없다.

3. 켜둔 도구가 매번 입력을 늘린다. [토큰 절약 가이드](https://datanexus-kr.github.io/curations/2026-09/2026-09-04-claude-code-token-optimization-guide/)는 연결 도구 설명이 프롬프트마다 실린다고 본다. 안 쓰는 연결이 있는지 확인할 만하다.
